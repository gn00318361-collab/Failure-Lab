# Failure Lab｜失敗學互動實驗室

> 讓學生不只是「聽懂失敗」，而是親自經歷：嘗試、犯錯、得到回饋、修正，再理解背後的心理學研究。

## 專案定位

Failure Lab 是《失敗學》簡報的互動實驗網站。

每一個網頁實驗都必須對應到簡報中的一個核心概念，基本教學流程為：

**提出問題 → 預測 → 親自實驗 → 看見自己的資料 → 研究揭曉 → 概念收束 → 帶回真實生活**

因此，本專案的目標不是製作「好玩的心理測驗」，而是把心理學研究轉化成學生可以親自體驗的學習活動。

## Lab #01｜錯誤有多遠？

### 核心問題

**錯誤只有「對」和「錯」嗎？**

還是我們也可以問：

> 「我離正確答案，到底有多遠？」

### 實驗流程

1. 觀看一個顏色 3 秒
2. 顏色消失
3. 評估自己記得多準
4. 從色環中選出記憶中的顏色
5. 系統計算與正確顏色的誤差角度
6. 得到正確答案的回饋
7. 經過短暫干擾後再次測驗
8. 比較第一次與第二次的誤差

### 學生看到的不是「分數」

例如：

- 第一次誤差：42°
- 第二次誤差：13°
- 修正幅度：29°

重點不是「42° 很差」。

重點是：

**第一次的錯誤，提供了下一次可以往哪裡修正的資訊。**

### 對應《失敗學》概念

**錯誤 → 回饋 → 更新 → 再嘗試**

教學收束：

> **失敗的價值，不在失敗本身，而在於它有沒有變成下一次行動的資訊。**

### 研究提醒

本活動受到 2026 年「learning from mistakes / error magnitude」相關研究啟發。

教學時避免簡化成：

> 「錯越大，學得越好。」

較精確的說法是：

> **錯誤的幅度可以形成學習與更新的訊號；在得到清楚回饋後，人可能依據這個差距調整後續表現。**

## 與《失敗學》簡報的搭配方式

建議流程：

### ① 簡報先問

> 「如果兩個人都答錯，他們的『錯』是一樣的嗎？」

### ② 掃 QR Code

全班進入 Failure Lab #01。

### ③ 不先公布研究

讓學生先完成實驗，看到自己的誤差與修正幅度。

### ④ 回到簡報

教師提問：

> 「第一次錯最多的人，第二次是不是也一定進步最多？」

讓學生先猜。

### ⑤ 揭曉研究

介紹「錯誤幅度」與「更新」的研究概念。

### ⑥ 最後收束

**錯誤不是判決，而是資訊。**

知道自己「差在哪裡、差多少」，才有機會決定下一步怎麼改。

## Failure Lab 發展方向

### Lab #01｜錯誤有多遠？
色環記憶 × Error Magnitude

### Lab #02｜六張圖卡
學生能不能真的利用失敗提供的資訊？

### Lab #03｜如果是你，你會怎麼建議？
失敗後替別人提供建議，是否改變我們面對自己失敗的方式？

### Lab #04｜你看見多少失敗？
Failure Gap：我們看到的成功與失敗，真的代表真實比例嗎？

## 核心原則

每新增一個 Failure Lab，都必須回答三個問題：

1. **學生親自經歷了什麼？**
2. **這個體驗對應哪一個心理學概念或研究？**
3. **做完之後，學生可以帶走哪一句話？**

如果只有「好玩」，但無法回答後兩題，就不加入 Failure Lab。
